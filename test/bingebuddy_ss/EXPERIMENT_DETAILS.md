# BingeBuddy - Demo Experiment Details

Use these details when creating a usability experiment in Heuristiq for the demo recording.

---

## Experiment Name

```
BingeBuddy Mobile App - Core User Flow Analysis
```

---

## Research Goal

```
Evaluate the usability and discoverability of key features in BingeBuddy's mobile app, including watchlist management, movie discovery, friend connections, and profile navigation for first-time users.
```

---

## Agent Instructions

```
You are a first-time user of BingeBuddy, a movie watchlist and social sharing app. Navigate through each screen and complete the following tasks:

1. Review your watchlist and understand how movies are organized
2. Try to add a new movie to your watchlist
3. Explore your friends' watchlists and see what they're watching
4. Attempt to add a new friend to your network
5. Check your profile stats and viewing progress

Report any confusion, friction points, or moments of delight. Focus on discoverability, visual hierarchy, and ease of navigation.
```

## Expected Insights

The AI personas should identify issues such as:
- Friend search requiring exact username (discoverability issue)
- Navigation clarity between screens
- Touch target sizes on mobile
- Visual feedback for actions (add to watchlist, add friend)
- Information hierarchy and cognitive load

---

## Recommended Personas

For a comprehensive test, use these personas:
1. **First-time User** - Low tech experience, high patience
2. **Social Media Enthusiast** - High experience, medium patience  
3. **Busy Professional** - Medium experience, low patience (mobile)
